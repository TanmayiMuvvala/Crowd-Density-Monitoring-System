# Vision-Based Crowd Density Monitoring and Automated Emergency Alert System

## Overview

This project presents a deep learning-based crowd monitoring system designed to detect crowd density and generate automated emergency alerts in real time. The system utilizes YOLOv8 for object detection and crowd analysis, enabling efficient monitoring of crowded environments and supporting public safety applications.

## Features

* Real-time crowd detection using YOLOv8
* Crowd density estimation and monitoring
* Automated emergency alert generation
* Dashboard-based monitoring and visualization
* Scalable architecture for public safety applications
